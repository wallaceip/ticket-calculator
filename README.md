
# Ticket Calculator

A lightweight web app that calculates ticket costs based on quantity, tier, and discounts. Built for Web Development 1 (Lab 5) at SAIT.

## Features

- Real-time calculation of subtotals, discounts, taxes, and final totals.
- Form input validation.
- Responsive layout for mobile and desktop.
- Vanilla implementation with zero dependencies.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)

## Quick Start

1. Clone the repository:
```bash
git clone [https://github.com/wallaceip/ticket-calculator.git](https://github.com/wallaceip/ticket-calculator.git)
cd ticket-calculator

```

2. Open `index.html` in any modern web browser.

## Project Structure

```text
├── index.html    # Page structure and form inputs
├── styles.css    # Layout and styling
└── script.js     # Calculation and DOM logic

```
